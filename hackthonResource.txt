🚀 Message 2:  Recommended ways to use Lemma

Please remember that your Lemma credits are limited. Use them mainly for testing and deploying once your product is ready. For the core building process, you will have to mainly use your IDE/coding agent/subscription/keys or try the OpenCode method shared in the guide.

Quickstart guide → https://lemma-quickstart.vercel.app/
It walks you through the easiest setup paths:

-> Developers — three options: run Lemma locally, use it in your IDE (Claude Code / Codex / Cursor + Lemma Cloud), or bring your own API key on lemma.work

-> Non-developers — use your Claude Code / Codex / OpenCode: paste one prompt and your agent does the whole setup
No subscription? A free path using OpenCode is included

💡 Heads up: your Lemma credits are limited — use them mainly for testing and deploying once your product is ready. For the core building, rely on your IDE / coding agent / subscription / keys, or the OpenCode method in the guide.

🪟 Message 3 — Windows users

The native Windows fix for installing the CLI + skills is coming tomorrow — we're testing it now. Until then, two ways to build on Windows:

Use WSL — run the local Lemma stack inside WSL (Windows Subsystem for Linux) + Docker Desktop, then follow the developer "use Lemma locally" steps in the guide.

Bring your own key — skip local install entirely: add your model-provider API key to a hosted pod on lemma.work and build in the browser → Find the guide for it here: "use my key on lemma.work" path on: https://lemma-quickstart.vercel.app/

We'll post here as soon as the Windows fix is live. 🙌

☁️ Message 5 — Host your locally-built pod on lemma.work

Built your pod locally and want it hosted?

Follow the "I want to use Lemma locally" section of the quickstart → https://lemma-quickstart.vercel.app/,

or refer to the README → https://github.com/lemma-work/lemma-platform

Using an IDE? Just ask your coding agent to import the pod to the cloud — it already has the Lemma builder skill installed, so it can do it for you.
