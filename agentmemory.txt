1. PRODUCT VISION
================================================================================

CareerOS IS:
  "Your personal AI recruiting department" — an autonomous AI workforce that
  continuously searches, analyzes, plans, and manages a person's career.

CareerOS IS NOT:
  - AI Resume Builder (it's an OS, not a tool)
  - AI Job Portal (it's an agent system, not a listing site)
  - Chatbot + GPT wrapper (it chains 4 Lemma agents in a pipeline)

Core Flow (Event-Driven):
  Resume Uploaded → Memory Updated → Jobs Scored → Match Analysis →
  Resume Optimized → Cover Letter → Application Planned → Interview Prep →
  Memory Updated → Dashboard Timeline → Notification

User uploads ONE PDF. Everything else happens automatically.

For judges: demonstrate Lemma as an OPERATING SYSTEM (workflows, chained agents,
memory, state, connectors) — not isolated API calls per page.

14. 4-AGENT CHAINED WORKFLOW — DETAILED FLOW
================================================================================

Trigger: POST /ai/autonomous or POST /ai/workflow/stream

Input: resume_text + job_description + company + job_id (optional)

STEP 1: opportunity-intelligence (Lemma agent)
  Input: Resume (4000 chars) + Job Description + Company name
  Output: {
    match_score: 85,
    strengths: [...], missing_skills: [...], matched_skills: [...],
    reasoning: "...",
    company_intelligence: {
      culture, tech_stack, hiring_trend, interview_process, salary_range, red_flags
    }
  }

STEP 2: career-mentor (Lemma agent)
  Input: Resume (3000 chars) + Step 1 results
  Output: {
    optimized_resume: "...",
    ats_suggestions: [...], keyword_suggestions: [...],
    skills: [{ name, difficulty, hours, resources, depends_on }, ...]
  }

STEP 3: application-strategist (Lemma agent)
  Input: Job Description + Resume + Step 1 + Step 2 results
  Output: {
    recommendation: "Apply Now|Wait|Skip", reasoning: "...",
    cover_letter: "...", recruiter_email: "...", linkedin_message: "...",
    follow_up_email: "...", recruiter_outreach: "...", follow_up_timeline: "...",
    checklist: [...],
    behavioral_questions: [...], technical_questions: [...],
    preparation_plan: "...", company_research: "...", tech_deep_dive: [...]
  }

STEP 4: career-memory (Lemma agent)
  Input: Step 1 + Step 2 + Step 3 summaries
  Output: { memory_saved: true, status: "synced", run_summary: "...", key_action: "..." }

Post-processing:
  - Updates AI memory (missing skills → skills_improving, company → applied_companies)
  - Caches result in workflow_results (keyed by user_id + job_id + resume MD5 hash)
  - Logs events to Mission Control timeline
  - SSE version sends real-time agent_start/agent_complete events

Fallback chain:
  Lemma agent → (if fails) → heuristic defaults
  Gemini direct path available but not currently in main pipeline (used in individual endpoints)

24. KNOWN GOTCHAS
================================================================================

1. Lemma token expires → run: lemma auth print-token (with mock_modules PYTHONPATH on Windows)
2. Gemini 429 → Lemma agents may also fail if using Gemini profile. Use system:lemma or wait.
3. Port 5002 conflict → kill old uvicorn before restart
4. Job descriptions contain HTML <br> tags → strip_html() in lemma_client.py before sending
5. POST /memory/ with only resume_text used to wipe fields → use PATCH or $set partial update
6. Fallback match gives ~35% with words like "and","based" → means NO real AI ran
7. Lemma credits limited → dev with Gemini key, demo with Lemma
8. Windows: lemma CLI needs $env:PYTHONPATH="career-os/mock_modules" for termios stub
9. Cached results use workflow_version="v4.0" — change version to bust cache after updates
10. SSE streaming uses native fetch() in frontend (not axios) — api.js has both patterns
11. MongoDB "jobagg" database must exist with job data from jobScraper for Jobs page to work
12. Agent response parsing: extract_json() handles markdown wrappers, nested JSON, regex fallback
13. Connector operations require user to have connected Google account in Lemma platform
14. The 6 original agent names (job-matcher, opportunity-scout, resume-advisor, interview-coach,
    career-mentor, application-strategist) were consolidated to 4 deployed agents in cloud bundle
